# bruce-growth-lab

The experimental growth lab under [kangxin.me](https://kangxin.me). A quieter, longer-form space for growth notes, frameworks, and case studies that don't fit on the main site's front page.

> 🔗 Live: **[kangxin.me/lab/](https://kangxin.me/lab/)**

## What lives here

- **Frameworks** — reusable growth decision frameworks
- **Case Studies** — teardowns of consumer / SaaS growth plays
- **Dialogues** — transcripts of product / growth conversations
- **Notes** — short-form growth observations
- **Growth Journal** — ongoing growth experiments

## Stack

Astro · TypeScript · Markdown content in `src/content/`

## Develop

```bash
npm install
npm run dev       # starts local dev at localhost:4321
npm run build     # outputs static site to ./dist/
npm run preview   # preview the build locally
```
